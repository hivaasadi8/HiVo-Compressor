## 🚀 راه‌اندازی

### ۱. Fork کن

### ۲. Secrets بساز

| نام | مقدار |
|:---|:---|
| `BOT_TOKEN` | از @BotFather |
| `ADMIN_ID` | آیدی عددی |
| `GH_PAT` | Personal Token با دسترسی `workflow` |
| `SUPPORT_USER` | (اختیاری) یوزرنیم پشتیبانی |

### ۳. Actions رو فعال کن

برو به تب **Actions** → **I understand my workflows** → فعال

### ۴. workflow رو اجرا کن

تب Actions → **HiVo Compressor** → **Run workflow**

## 🔄 اجرای ۲۴/۷

- هر ۵ ساعت ری‌استارت خودکار
- اجرای دستی با `workflow_dispatch`
- ذخیره داده در خود ریپو
